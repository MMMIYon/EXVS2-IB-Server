# Server-Infinite 1.0 （红高达版本）

## 写在最前
基于 POC 的遗产进行改进，完善了主要的功能，但毕竟是带逆向性质的工作，与原生 Server 必然有差距，望理解

## Bugfix（与v0.1丐版相比）
1. 修复了设置偏好机体会导致通信错误的 bug
2. 修复了练习模式和关卡模式不会记录熟练度的 bug
3. 修复了自定义通讯和贴纸无法使用的 bug
4. 修复了无法预设操作模式和键位提示的 bug
5. 卡片训练场设置已经与游戏内训练场设置对齐

## Feature（IB 新增的主要功能）
1. 到红高达为止的新机体追加
2. 到雀雀为止的新领航员追加
3. 偏好机体上限增加至 12 台
4. “快速开始”功能现在可以正常使用，卡片设置中追加功能开关
5. Miku 联动通讯贴纸已追加
6. 各模式自定义通讯可以分别设置，详见卡片设置
7. 增加拒收通讯和自动发送通讯的功能开关
8. 开幕贴纸可以展示驾驶员立绘，可在常规立绘与觉醒 cutin 间切换
9. 开幕贴纸中的机体 pose 与驾驶员立绘的设置逻辑变更，支持多选，实际开幕元素将从选择项中随机抽取

## Unhandled（目前明确未完善的）
1. Online对战模式和大会模式没有做，本地的话应该用不到
2. BGM 列表有变，精力有限没能一一列举，卡片设置里开放使用 ID 指定 BGM，有劳大家自行尝试交流
3. Title 在 IB 被边缘化了，装饰、特效什么的全都没了，Title 内容也大幅调整了，同样精力有限没能一一列举，开放以 ID 形式指定 Title，有劳大家自行尝试交流（Title 真的很边缘，显示的场景很少）
4. IB UI 改动，连带着自定义 UI 也大幅变化，虽然收录了 UI 的预览，但是没能一一校验名称，全部以 Gauge+数字ID 的形式指代
5. 据说 Miku 联动还有一首 BGM 和一个贴纸背景，也很遗憾没有找到
6. 本地化文本可能存在纰漏，尤其是港台繁中的机体名、人物名，本人了解有限，欢迎勘误
7. 测试未完全覆盖所有地方，可能存在此处未列出的 bug，欢迎反馈

## Tips（补充说明）
1. BGM Safe Mode，这个设置好像是为了直播/录制准备的（某些 BGM 可能存在版权问题？），开启这个选项会无视自定义 BGM 设置
2. 败方通讯固定发「ありがとうございます」，所以不要问结束时自定义通讯为什么不生效
3. 自动发送通讯的功能会无视掉战斗中的四方向自定义通讯设置，但是开幕和结束时的还是会生效
4. 训练场设置里关于耐久值有个“Revive”（战损）选项，不能在卡片设置里设置，只能在游戏内选取
5. 现代模式（Lite Type）是改不了键位的
6. 操作模式有“Normal Type (Default)”和“Normal Type (Custom)”之分，想使用自定义键位请选择后者
7. 机体贴纸设置里多了个 Sub Background 的设置，这个对应的是在开幕贴纸中显示驾驶员立绘时的那部分背景，但是美术素材复用了贴纸背景，所以卡片设置预览也直接复用了，实际效果看了就会明白的
8. 为了增加闲鱼骗子转卖的难度，现在启动时会有弹窗提示，五秒钟自动关闭，而且不会阻塞主程序启动，所以正常使用时可以直接无视，主要起提示之用（闲鱼骗子私募了）
9. 卡片设置网页若异常（持续白屏、旧版网页），请“清除该站点数据”（不会的问豆包）
